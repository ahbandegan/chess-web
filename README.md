# شطرنج آنلاین و پیشرفته (WebRTC Peer-to-Peer)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Pure Vanilla JS](https://img.shields.io/badge/Language-Vanilla%20JS%20%7C%20HTML5%20%7C%20CSS3-brightgreen.svg)]()
[![Zero Backend](https://img.shields.io/badge/Backend-Zero%20PHP%20%2F%20Static-orange.svg)]()

یک بازی شطرنج حرفه‌ای، مدرن و کامل با رابط کاربری **Material Design 3** که به صورت **۱۰۰٪ کلاینت‌ساید (Client-Side)** توسعه یافته است. این پروژه را می‌توانید روی هر سرور PHP، هاست لینوکسی، cPanel، دایرکت‌ادمین یا حتی هاست‌های استاتیک، **بدون نیاز به حتی یک خط کد PHP، بدون پایگاه‌داده (MySQL) و بدون نیاز به نصب Node.js** اجرا کنید.

---

## 🚀 راهنمای استقرار روی سرور PHP و انواع هاست
برای اجرای این بازی روی وب‌سرور یا هاست خود:
1. تمامی فایل‌ها و پوشه‌های این پروژه را کپی کنید:
   - `index.html`
   - `css/`
   - `js/`
   - `LICENSE`
   - `README.md`
2. آن‌ها را در مسیر روت وب‌سایت (`public_html`) یا هر زیرپوشه دلخواه (مثلاً `public_html/chess`) آپلود کنید.
3. آدرس را در مرورگر باز کنید (مانند: `https://your-domain.com/chess/`).
4. بازی بلافاصله و با تمام امکانات (از جمله بازی آنلاین دو نفره) اجرا می‌شود!

## 🌟 قابلیت‌ها و امکانات

### ۱. بازی آنلاین دو نفره (Online 2-Player via WebRTC P2P)
- **ارتباط مستقیم همتا‌به‌همتا (P2P):** ارتباط لحظه‌ای و بدون تأخیر (Zero Latency) با استفاده از فناوری مدرن WebRTC (کتابخانه PeerJS).
- **لینک مستقیم دعوت:** امکان ساخت اتاق با یک کلیک و دریافت کد اتاق ۵ رقمی یا لینک مستقیم اختصاصی (`?room=XYZ`) برای ارسال در پیام‌رسان‌ها (تلگرام، واتساپ، ایتا و ...).
- **کنترل زمان مسابقه (Clock):** ساعت شطرنج هماهنگ و لحظه‌ای با حالت‌های ۱ دقیقه (Bullet)، ۳ و ۵ دقیقه (Blitz)، ۱۰ و ۱۵ دقیقه (Rapid/Classical) یا بدون زمان (نامحدود).
- **چت و واکنش‌های لحظه‌ای:** قابلیت ارسال پیام متنی و ایموجی‌های انیمیشنی (👍, 🔥, 😭, 🤯, 👏) در حین بازی.
- **پیشنهاد تساوی و تسلیم:** ارسال و دریافت درخواست تساوی توافقی یا تسلیم شدن در هر لحظه.

### ۲. گرافیک و طراحی استاندارد بین‌المللی
- **وکتورهای رسمی و مسابقاتی مهره‌ها (SVG):** طراحی رسمی مسابقات فیده اثر کالین برنت (**Colin Burnett / Wikimedia Commons**) با بالاترین دقت در جزئیات (یال و پوزه اسب، تاج وزیر و پادشاه و ...) با مقیاس‌پذیری نامحدود روی صفحات Retina و 4K.
- **ابعاد پایدار و ضد پرش (Zero Layout Shift):** صفحه کاملاً با نسبت ۱:۱ در تمامی دستگاه‌ها قفل شده و هنگام زدن مهره‌ها یا تغییر امتیاز هیچ پرش یا تغییر اندازه‌ای رخ نمی‌دهد.
- **۴ تم چشم‌نواز برای صفحه:**
  - سبز مسابقاتی (Tournament Green)
  - چوبی کلاسیک (Classic Wood)
  - آبی یخی (Ice Blue)
  - میدنایت تاریک (Midnight Dark)

### ۳. رعایت ۱۰۰٪ قوانین رسمی فیده (FIDE Rules)
- پیاده‌روی آن‌پاسان (En Passant)
- قلعه کوچک و بزرگ (Castling)
- پنجره انتخاب مهره هنگام ارتقاء پیاده (Pawn Promotion) به وزیر، رخ، فیل یا اسب
- تشخیص هوشمند کیش (با نور و انیمیشن قرمز دور پادشاه)، مات و انواع حالت‌های پات و مساوی (مات نبودن، مهره‌های ناکافی، قانون ۵۰ حرکت، تکرار سه‌باره موقعیت)

### ۴. افکت‌های صوتی طبیعی با Web Audio API
- بدون نیاز به فایل‌های صوتی خارجی (MP3/WAV) که ممکن است با خطای ۴۰۴ مواجه شوند؛ تمامی صداها (حرکت چوبی، ضربه گرفتن مهره، هشدار کیش، صدای قلعه، پیروزی و شکست) به صورت درلحظه توسط سینتی‌سایزر صوتی مرورگر تولید می‌شوند.

### ۵. هوش مصنوعی و بازی محلی
- **بازی با هوش مصنوعی (کامپیوتر):** الگوریتم Minimax با هرس آلفا-بتا (Alpha-Beta Pruning) و جداول ارزش‌گذاری پوزیسیونی در ۳ سطح دشواری (مبتدی، متوسط، استاد).
- **بازی دو نفره محلی (Pass & Play):** بازی دو نفره روی یک گوشی، تبلت یا لپ‌تاپ همراه با دکمه چرخش ۱۸۰ درجه صفحه.
- **ثبت تاریخچه حرکات و خروجی PGN:** جدول حرکات با نماد استاندارد جبری (SAN) و امکان کپی متن استاندارد PGN با یک کلیک.

## 📂 ساختار فایل‌های پروژه

```text
chess/
├── index.html        # اسکلت اصلی برنامه و دیالوگ‌های متریال ۳
├── LICENSE           # متن رسمی پروانه نرم‌افزار آزاد GPLv3
├── README.md         # مستندات و راهنمای استقرار
├── css/
│   └── style.css     # استایل‌های متریال ۳، ابعاد ضد پرش و متغیرهای رنگی
└── js/
    ├── chess.min.js  # کتابخانه استاندارد قوانین FIDE
    ├── peerjs.min.js # کتابخانه ارتباط WebRTC P2P کلاینت‌ساید
    ├── pieces.js     # وکتورهای استاندارد مسابقاتی مهره‌های شطرنج
    ├── audio.js      # موتور تولید صدا با Web Audio API
    ├── engine.js     # هوش مصنوعی مجهز به Minimax و Alpha-Beta
    ├── p2p.js        # مدیریت ارتباط دو نفره، چت و پیام‌های شبکه
    └── app.js        # کنترلر اصلی رویدادها، تاچ و درگ‌واند‌دراپ
```
